第1部：B-System Alpha 1「Ceremony」公式リリース
Part 1 — Official Announcement: B-System Alpha 1 ("Ceremony")

「初めてマシンに火を入れる瞬間は、賭け事ではなく厳粛な儀式であるべきだ —— スキー・ブートローダーはすべての起動を意図的で、美しき所作へと昇華させる。」
"The first time you turn on a machine should feel like a ceremony, not a gamble — Bootloader makes every boot a deliberate, beautiful act."

Synrc Research Centerは、B-System Alpha 1（バージョン 3.20-alpha.1、コードネーム「Ceremony」）の正式公開をお知らせします。 B-Systemは、日本のパーソナルコンピュータ規格の金字塔であるBTRON3 SPEC 3.20仕様に準拠したクリーンルーム再構築OSです。標準C99で設計され、坂村健博士とTRONプロジェクトが提唱した直感的な造形美、リアルタイム応答性、そして実身・仮身ハイパーデータ構造を現代のオープンソース環境に甦らせます。

Alpha 1 の主な機能と到達点（Release Highlights）

集中的なシステム開発を結実させ、単一C99コードベースから完全に再現可能なリリースパッケージを構築しました：

  • 16アーキテクチャ統合対応： 単一のBSD Makefileから、POSIX開発ホスト、ARM QEMU VirtIO、Raspberry Pi 2B/3B/4B/400実機ベアメタル、坂村T-Kernel 2.0、x86_64 UEFI SMPワークステーション、NEC PC-9801/PC-9821 VM、Motorola 68040、MIPS32r2、Sony PlayStation 2（Emotion Engine）、FOMAモバイル、PlayStation 3 PPU、およびRP2040/RP2350 PicoCalcまでを統合起動。
  • ダイレクトMultiboot単一段階ローディング： 脆弱な2段階MBR/VBRチェーンローダーを撤廃し、Multiboot 1ヘッダー（0x1BADB002）によりファームウェア／QEMUから1MB空間へ直接展開。
  • 本物の「実身／仮身」ハイパーデータエンジン： 文書内にキャビネット内の実身（Real Body）へのポインタ（仮身・Virtual Body）を無制限に埋め込める坂村ハイパーメディア構造を忠実に実装。
  • Mozc TIPネイティブ日本語・チベット語・サンスクリット語多言語基盤： Google Mozcかな漢字変換エンジン（mozc_kkc.c）、TRON Text Input Primitives（TIP/IFE）、チベット文字EWTS Wylie入力、注音符号（Bopomofo）、およびサンスクリット語デーヴァナーガリー書体を内蔵。
  • 創作・開発・エミュレーション統合アプリケーション群： Workbench、Terminal、Commander、Editor、Clarity、Review、Browser、Mail/Chat、Cassette、Paint、Orchestra DAW、Quake I 3D、B-MSX、ANS Forth、Media Matrix SDK、Volumes、および10種の環境設定アプレットを完備。
  • 公式TAD電子書籍群を標準同梱： BTRON3仕様書、T-Kernel 2.0、B-Free OS（1994年）、B-System（2026年）、およびB-Book技術仕様書をバイナリTAD（.tad）として自動生成・格納。
  • 適合性テスト90%合格と形式検証： 370項目（全410検証項目中90.2%）の仕様要件が自動検証スイートを通過。さらにCoq定理証明器によるマイクロカーネル・B-FS・メディアパイプラインの数学的安全性検証を併設。

対応カーネル一覧と先駆者トリビュート（Unified Targets & Pioneer Tributes）

B-Systemでは、日本の組み込みリアルタイムOSおよびシステムプログラミングの道を切り拓いた先駆者たち（高田広章、常田浩、横林貴広、坂村健、内田公太、Awe Morris、横山孝典、板垣史彦、久夛良木健、進藤雅弘、新部裕、本田晋也）への敬意を込め、各ターゲットにその名を冠しています。各カーネルの詳細な機能・アーキテクチャ解説および起動コマンドは、ブートローダー製品ページ（Boot.html）の統合カーネル表にて完全掲載されています。

第2部：初コミットからの全開発記録
エンジニアリング・ログ (Development History Log)

B-Systemは、マキシム・ソハツキー（Maxim Sokhatsky / Namdak Tonpa / 5HT）により、2026年8月22日から11月24日までの95日間にわたる集中的な開発スプリントで設計・実装されました。計1,262コミット、136セッション（実稼働約595.2時間）にわたり、空のGitリポジトリから、極小のRP2040マイクロコントローラやFPGA SoC、PlayStation 2/3、そして64ビットUEFI SMPワークステーションまでを単一C99ソースツリーで貫く仕様準拠OSへと進化を遂げました。

Engineered by Maxim Sokhatsky (Namdak Tonpa / 5HT) across a continuous 95-day sprint (August 22 – November 24, 2026), B-System evolved through 1,262 commits and 136 active sessions (~595.2 engineering hours) from an empty repository into a cleanroom BTRON3 3.20 operating system spanning 16 hardware targets, formal Coq proofs, real-time 3D/DAW subsystems, and deterministic embedded toolkits. Each phase card below consolidates the underlying session telemetry into a dual-language architectural release chronicle.
