Raspberry Pi 500

Pi 5 class machine, BCM2712.

The ARM64 port brings up a Pi 5 framebuffer through btron_rpi5_mailbox_init in src/drivers/broadcom/boot_arm_stub.c. This tree does not yet emit a separate Pi 500 card image. The Pi 400 image is the packaged Broadcom card: see Pi 400.
