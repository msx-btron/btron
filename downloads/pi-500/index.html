Downloads · Broadcom ARM64

Raspberry Pi 500

Pi 5 class machine, BCM2712.

Technical Characteristics of the Computer/Console

ChipsetBroadcom BCM2712 (Quad-core ARM Cortex-A76 @ 2.4 GHz, AArch64) + RP1 I/O Southbridge
BusPCIe Gen 2 ×1 (RP1), VideoCore VII Mailbox property channel, SDIO
VideoVideoCore VII GPU (BCM2712 framebuffer via btron_rpi5_mailbox_init in src/drivers/broadcom/boot_arm_stub.c)
DisplayDual micro-HDMI (up to 4K60); B-System LAPTOP shell (1280×1024 / 1024×768 / 800×600, 32-bpp)
SoundHDMI digital audio, USB Audio Class 1 (src/drivers/broadcom/usb_audio_uac1.c)
InputIntegrated USB keyboard, USB HID mouse via xHCI (src/drivers/broadcom/xhci.c)
Memory8 GB LPDDR4X-4267 SDRAM
CommunicationsGigabit Ethernet, Wi-Fi 802.11ac, Bluetooth 5.0 (BLE), UART0 serial
