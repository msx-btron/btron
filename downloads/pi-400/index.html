Raspberry Pi 400

make pi400 writes btron-pi400.img.

make pi400 builds btron-pi400.img, a FAT image with the ARM64 kernel. make flash-pi400 writes an SD card. Firmware fetch is make fetch-pi400-fw. The board files are src/drivers/broadcom/pi400/.
