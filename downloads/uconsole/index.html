uConsole

Clockwork handheld on a Pi-class module.

The uConsole is a handheld shell around a Compute Module. It uses the Broadcom port in src/drivers/broadcom/ and the handheld UI in src/desktop/ui/handheld/. This tree does not ship a separate uConsole image target.
