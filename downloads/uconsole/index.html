Downloads · ClockworkPi Handheld

uConsole

ClockworkPi handheld on a Raspberry Pi Compute Module 4.

Technical Characteristics of the Computer/Console

ChipsetRaspberry Pi Compute Module 4 (Broadcom BCM2711 Quad-core ARM Cortex-A72 @ 1.5 GHz, AArch64)
BusCM4 PCIe / USB 2.0 hub, MIPI DSI, GPIO / I²C, SDIO
VideoVideoCore VI GPU, DSI / Mailbox framebuffer (src/drivers/broadcom/)
Display5.0-inch IPS LCD (1280×720); B-System HANDHELD & LAPTOP shells (src/desktop/ui/handheld/)
SoundDual stereo speakers, 3.5 mm headphone jack, micro-HDMI audio, USB Audio Class 1
InputIntegrated backlit QWERTY keyboard, mini trackball, D-pad & action keys (USB HID)
Memory4 GB / 8 GB LPDDR4 SDRAM (CM4 module)
CommunicationsWi-Fi 802.11ac, Bluetooth 5.0, optional 4G LTE modem module, USB-C, UART
