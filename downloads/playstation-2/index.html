Downloads · Sony Emotion Engine

PlayStation 2

make ps2 builds the Emotion Engine kernel ELF and bootable ISO9660 disc image.

Technical Characteristics of the Computer/Console

ChipsetSony Emotion Engine (MIPS R5900 128-bit SIMD @ 294.912 MHz) + IOP (MIPS R3000A @ 36.864 MHz)
Bus128-bit EE main bus, 10-channel DMAC, SIF (EE↔IOP RPC/DMA), GIF/VIF, OHCI USB 1.1, CDVD
VideoGraphics Synthesizer (GS @ 147.456 MHz, 4 MB eDRAM) + VU0/VU1 vector units (src/drivers/playstation2/, EEGS backend)
DisplayVESA 800×600 @ 32-bpp RGBA / NTSC 640×448 interlaced (Composite, Component, RGB SCART, VGA)
SoundSPU2 (48 hardware ADPCM voices, 2 MB sound RAM)
InputDualShock 2 controller (ps2_pad.c), USB HID keyboard & mouse via OHCI (ps2_usb.c, ps2_kbd.c)
Memory32 MB RDRAM (EE main RAM), 4 MB GS eDRAM, 2 MB IOP RAM, 16 KB Scratchpad
CommunicationsEE SIO serial (ps2_sio.c), PS2 Network Adaptor (100 Mbps Ethernet), i.LINK (IEEE 1394)
