Downloads · x86-64 UEFI SMP

Intel UEFI

make uefi builds the x86-64 UEFI SMP kernel; make storage-images builds USB, HDD, and CD media.

Technical Characteristics of the Computer/Console

Chipsetx86-64 / EMT64 SMP (4 cores via ACPI 6.5 MADT & Local APIC, src/cores/core_smp.c, T-Kernel 2.0)
BusPCIe / Intel Q35 chipset, VirtIO-PCI (src/drivers/virtio/), VirtIO-Block / AHCI
VideoVirtIO-GPU 2D & VESA VBE linear framebuffer (src/drivers/vesa/), TinyGL 3D rasterizer
Display1024×768 / 1280×1024 / 800×600 @ 32-bpp ARGB; B-System LAPTOP shell
SoundAC'97 / Intel HDA / PC speaker
InputPS/2 keyboard & mouse (src/drivers/uefi/ps2_mouse.c), USB HID
Memory1 GB+ linear 64-bit address space
Communications16550A COM1 UART serial, VirtIO-Net Ethernet
