Raspberry Pi 2

Broadcom BCM2836 ARMv7 port (make arm-elf, make run-kernel on QEMU raspi2b).

Technical Characteristics of the Computer/Console

ChipsetBroadcom BCM2836 (Quad-core ARM Cortex-A7 @ 900 MHz, ARMv7-A / VFPv4, T-Kernel 2.0)
BusAXI / APB peripheral bus, DWC2 USB 2.0 (src/drivers/broadcom/dwc2.c), VideoCore Mailbox, SDIO
VideoVideoCore IV GPU, Mailbox linear framebuffer (src/drivers/broadcom/)
DisplayFull-size HDMI; B-System LAPTOP shell (800×600 / 1024×768, 32-bpp)
SoundHDMI audio, 3.5 mm PWM audio, USB Audio Class 1 (src/drivers/broadcom/usb_audio_uac1.c)
InputUSB HID keyboard & mouse via DWC2 (src/drivers/broadcom/dwc2.c)
Memory1 GB LPDDR2 SDRAM
Communications100 Mbps Ethernet (LAN9514 USB hub), PL011 UART serial
