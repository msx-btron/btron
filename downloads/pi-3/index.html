Raspberry Pi 3

Broadcom ARM port.

Pi 3 is covered by the Broadcom drivers in src/drivers/broadcom/ and the ARM64 kernel. A dedicated card image is not a separate make target in this tree. Use the Pi 400 image path as the packaged Broadcom build, and the driver sources for the board bring-up.
