NEC PC-98

make pc98 builds the PC-98 T-Kernel 2.0 kernel (make run-pc98).

Technical Characteristics of the Computer/Console

ChipsetIntel i386 / i486 / Pentium (NEC PC-9801 / PC-9821 architecture, T-Kernel 2.0)
BusC-Bus (16-bit expansion bus), PCI (PC-9821), IDE / SCSI
VideoNEC µPD7220 GDC (text & planar VRAM) + PEGC / VESA linear framebuffer (src/drivers/pc98/)
Display640×400 (24 kHz) / 640×480 / 800×600 (31 kHz)
SoundYamaha YM2203 (PC-9801-26K) / YM2608 (PC-9801-86) FM + PCM, beep timer
InputPC-98 serial keyboard, bus mouse (PS/2 mouse compat under QEMU)
Memory16–64 MB RAM (1 GB under QEMU q35 compat)
CommunicationsIntel 8251A RS-232C UART, C-Bus Ethernet (NE2000-compat)
