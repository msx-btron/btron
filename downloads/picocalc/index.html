Downloads · ClockworkPi RP2040 / RP2350

PicoCalc

UF2 and SD-boot firmware for RP2040 and RP2350 (make picocalc-all, make picocalc-quake, make picocalc-tkernel).

Technical Characteristics of the Computer/Console

ChipsetRaspberry Pi RP2040 (Dual ARM Cortex-M0+ @ 133 MHz) or RP2350 (Dual ARM Cortex-M33 @ 150 MHz)
BusSPI (display & SD card), I²C (STM32 keyboard & power controller), QSPI XIP Flash, PIO
VideoSoftware framebuffer + PicoGL fixed-point 3D rasterizer (src/desktop/graphics/picogl/) over SPI DMA
Display4.0-inch IPS LCD, 320×320 RGB565 (ST7796S / ILI9488); B-System POCKET / SE-GUI compact shell
SoundDual PWM stereo speakers & 3.5 mm headphone jack
Input67-key backlit QWERTY keyboard + directional keys via STM32 I²C controller (src/drivers/pico/)
Memory264 KB SRAM / 2 MB Flash (RP2040) or 520 KB SRAM / 4 MB Flash (RP2350) + 8 MB QSPI PSRAM
CommunicationsUSB-C (BOOTSEL / CDC), UART0 (GP0/GP1, 115200 8N1), optional Wi-Fi / BLE (Pico W / Pico 2 W)
