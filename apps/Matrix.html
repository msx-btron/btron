1. 対応モード一覧 (Supported Rezmason/matrix Modes)

全 6 モードを単一のデータ駆動テーブル（src/media/matrix/matrix_modes.h）で管理し、実行中に 1〜6 キーまたはシェル引数で即時切替が可能です。

キー / ID モード (Mode) フォント (TTF) 視覚・数理仕様 (Visual & Mathematical Spec)
1 / trinity Trinity Matrix-Resurrected.ttf 3 層ボリュメトリック視差（遠・中・近）、脱彩エメラルド＋黄金メタリックグリント
2 / classic Classic (Default) Matrix-Code.ttf 1999/2003 オープニング準拠のエメラルド緑〜白熱カーソル、事前計算 3×3 ブルーム
3 / resurrections Resurrections Matrix-Resurrected.ttf 2021 年版 138 グリフ集合（U+E900..U+E989）、シアン寄りの高輝度ハイライト
4 / operator Operator Matrix-Code.ttf ネブカドネザル号コンソール調の平坦高密度グリッド＋チェビシェフ矩形波リップル
5 / megacity Megacity Matrix-Code.ttf 『レボリューションズ』風の大型グリフ（40 列基準）と重厚な落下速度
6 / pride Pride Matrix-Code.ttf 6 色プライドフラッグ（赤・橙・黄・緑・青・紫）の行 LUT カラーマッピング

2. 描画アーキテクチャ選定: Raw BitBlit vs. OpenGL (B-GL)

B-System の B-GL（gl_dispatch.h）は固定機能 OpenGL ES 1.1 でありプログラマブル・フラグメントシェーダを持たず、POSIX / QEMU / UEFI / PC-98 等では CPU ソフトウェアラスタライザ（TinyGL / VirGL）で動作します。そのため、ネイティブ wnd.c + GDEV への直接整数 BitBlit を採用しました。

設計要素 実装方式 (Implementation) 実測性能・メモリ効果
TTF ラスタライズ クリーンルーム Q16.16 libschrift（src/desktop/font/schrift.c） 起動時／リサイズ時のみ実行、動的ヒープ確保ゼロ（NASA JPL Rule 3）
差分セル・カリング 32-bit 状態キー（glyph|bright|cursor|glint）比較による未変化セルのスキップ 640×480 Classic で 約 67 µs/frame（理論 14,900+ FPS、60 FPS 時 CPU < 0.5%）
非 FPU 最適化 (PicoCalc) sft_render_q16() + 4-bit パックアトラス + RGB565 行バンド転送（dp_pico_blit_rgb565） RP2040 (Cortex-M0+) でソフト浮動小数点ゼロ・内側ループ除算ゼロ、SRAM < 22 KiB、TTF は Flash .rodata（28 KB）

環境 / 操作 コマンド / キー 動作
